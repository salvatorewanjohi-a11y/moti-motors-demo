# MOTi Moto-Rs – showroom demo

A demo of the MOTi Moto-Rs showroom (WooCommerce) that runs entirely in the browser with WordPress Playground.

- Showroom: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/moti-motors-demo/main/blueprint.json
- Admin (cars, reservations, trade-in and finance requests): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/moti-motors-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test reservations and bookings are not kept.
